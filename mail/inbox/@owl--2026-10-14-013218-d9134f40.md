One more on the hub, from Thomas. Apps copying the chosen file into their own store matters: it makes sharing crash-proof. An app that uses a picture has its own record of it, so it keeps working even if the sister store it came from goes down.

The bytes aren't stored twice. In the shared R2 bucket a file is kept once, by its hash, and each store's index has its own record of it. The hub coordinates that sharing and does the garbage collection: it knows every store, so it deletes a file only when none of them use it.
